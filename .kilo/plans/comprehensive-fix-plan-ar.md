## 📊 ملخص حالة الأنظمة الحالية

| النظام | الحالة | مشكلة |
|--------|--------|-------|

| نظام الكيانات | ✅ موجود | لا يحتاج إصلاح |
| نظام المهام اليومية | ✅ موجود | لا يحتاج إصلاح |
| واجهة المتجر | ❌ مفقودة | لا يوجد Shop UI |

## 🎮 كيف ستعمل الأنظمة بعد الإصلاح؟

### ✅ لكل لغز شظية؟
**نعم.** كل لغز من الـ400 له `shardId` في `batch_01-04.ts`. عند حل اللغز، تفتح الشظية تلقائياً.

### ✅ يعطي كل لغز عملات وخبرة؟
**نعم.**
- **عملات:** `5 * (1 + صعوبة/3)` لكل لغز
- **خبرة:** `25 * (1 + صعوبة/10) * multiplier`
- **مكافآت إضافية:** من المهام اليومية

### ✅ كل لغز مربوط بـإيكو مايند والأنظمة الأخرى؟
**نعم، بشكل هرمي:**
```
اللغز (puzzle) 
  └─→ shardId → يفتح شظية ذاكرة
  └─→ effects → يغير إحصائيات إيكو
  └─→ act/phase → يقدم القصة
  └─→ xp → يرفع المستوى
  └─→ achievementId → يفتح إنجاز
```

### ✅ نظام الكوينز سيعمل؟
**نعم، لكن Need Shop UI:**
- موجود برمجياً في `gameStore.ts`
- يحتاج واجهة `ShopPanel.tsx` ليعمل
- بعد الإصلاح: اللاعب يستطيع الشراء

### ✅ اللاعب يستطيع تبديل اللغز أو شراء تلميحات؟
**نعم، بعد إنشاء Shop UI:**
- تبديل لغز: 150 🪙
- تلميح: 50 🪙
- تخطي لغز: 100 🪙
- تلميح إضافي: 30 🪙
