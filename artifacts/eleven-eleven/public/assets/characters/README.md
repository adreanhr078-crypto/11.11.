# Character Presentation Assets

`echo-portrait-v1.png` is an original, replaceable presentation key art used by
`EchoPresence`. It is not narrative content and does not define Echo's identity,
stats, expressions, or gameplay state.

Runtime emotion, corruption, scan, glitch, breathing, entry motion, and color
grading are applied by CSS and the existing Emotion Visual System. A future art
pipeline can replace the portrait or introduce expression-specific assets
without changing domain systems.

The source was generated with the built-in image generation workflow using the
provided UI references for palette, atmosphere, and interface mood only.
