# Godot portable engine smoke

This is a neutral, non-Canon technical proof. It verifies only that the pinned
portable Godot Standard editor can import a project, parse a scene and GDScript,
instantiate basic 3D nodes, and exit headlessly with an explicit success marker.

It does **not** select Godot as the 11.11 production runtime, prove visual
quality, authorize an open world, or own authentication, saves, rewards, story,
or gameplay state. Generated `.godot` state and logs stay ignored.
