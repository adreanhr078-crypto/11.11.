# Echo and Yuki character reference lock

Status: `STEP 2 — MODEL SHEET / RIG FOUNDATION`

These model sheets are project-bound production references. They are not
runtime assets and they do not make the current Manhwa's later events Canon.

## Identity lock

- Echo is the black-haired main protagonist and the character who transforms.
- Echo has red/cyan heterochromia and the skin tattoo `EX-011`.
- Yuki is the white-haired supporting character with light violet eyes and the
  skin tattoo `EX-012`.
- Both identifiers belong on exposed neck skin. They are never collar labels,
  UI, authoritative state, or puzzle evidence.

The Owner confirmed that the deeper story and much of the Manhwa will change.
Only the opening premise and the recognizable faces are stable inputs. Outfit
layers, transformation geometry, cinematic staging, and story symbols must
remain modular and replaceable.

## Files and provenance

- `echo-ex011-model-sheet-v1.png` was generated specifically for 11.11 from
  project-owned Echo character assets on 2026-08-28.
- `yuki-ex012-model-sheet-v1.png` was generated specifically for 11.11 from
  the project-owned Yuki avatar and an early friendship page on 2026-08-28.

The generated sheets intentionally omit readable identifiers because image
generation cannot guarantee exact typography. Blender adds the exact tattoos
as geometry bound to the neck bone.

## Production boundary

The sheets guide silhouette, proportions, materials, and modular clothing.
They do not authorize publishing an AI-generated image as final character art.
The first Blender output is a rigged production blockout. A final hero-quality
model still requires topology, facial rigging, texture painting, deformation
review, LODs, and performance validation before runtime integration.
