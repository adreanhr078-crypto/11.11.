# Edge Verification — Playwright MCP

قدرة التحقق بالمتصفح على **Microsoft Edge** لمشروع 11.11 (أولوية AGENT_RULES:
الشاشة البيضاء + فحص Edge). الإعداد على مستوى مساحة العمل ولا يلمس أي ملف إنتاجي.

## ما أُعدّ

- `.vscode/mcp.json` — سيرفر MCP باسم `playwright-edge`:
  `npx -y @playwright/mcp@0.0.79 --browser msedge`
  (الإصدار مثبَّت عمداً لضمان التكرارية؛ لا يستخدم latest).
- يعتمد على `playwright@1.62.1` المثبت في جذر المستودع وكاش المتصفحات في
  `%LOCALAPPDATA%\ms-playwright`، وقناة Edge المثبتة على النظام.

## كيف تستخدمه

1. افتح مساحة العمل في VS Code → سيرفرات MCP → شغّل `playwright-edge`.
2. شغّل بيئة التطوير (`npm run dev` داخل `artifacts/eleven-eleven`،
   الواجهة على `http://localhost:3000` والـ API على `8788`).
3. اطلب من الوكيل مهام تحقق مثل:
   - فحص الشاشة البيضاء: فتح الصفحة + لقطة شاشة + قراءة أخطاء Console.
   - رحلة اللاعب: Story → Puzzle → لحظة الإكمال والمكافأة.
   - RTL وReduced Motion والوصولية (لقطات + فحوص DOM).
   - أدلة أداء: حجم الطلبات، LCP/INP عبر تتبع الشبكة.

## قواعد استخدام آمنة

- التحقق ضد `localhost` فقط — لا توجّه السيرفر إلى بيئة الإنتاج.
- لا تمنح السيرفر أي بيانات اعتماد إنتاجية؛ استخدم بيانات `.dev.vars`.
- كل دليل بصري/تشغيلي يجب أن يُرفق في التقارير (لا تختلق نتائج PASS).

## ملاحظة

`chromium.launch({ channel: 'msedge' })` → فتح صفحة، قراءة نص، والتقاط
لقطة — **PASS** على Node v24.16.0 / Windows.
