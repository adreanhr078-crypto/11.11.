# سلطة Canon السردية الداخلية

يحتوي هذا المجلد على المرجع القصصي المعتمد لمشروع **11.11**، تحت إصدار Canon:
`long-fall-v1`.

- **الرؤية:** داخلي فقط (`internal`) وليس للنشر العام.
- **وقت التشغيل:** الملفات الكاملة لا تدخل حزمة اللعبة (`runtimeIncluded: false`).
- **الحرق:** المحتوى يتضمن حرقًا كاملًا (`spoilerLevel: full`).
- **الحالة:** سلطة Canon معتمدة (`canonical-authority`).
- **حالة القصة:** مستمرة وغير مكتملة (`ongoing`).

يجب أن تستخدم اللعبة الإسقاط الآمن الموجود في `src/lore.ts`. لا تُنقل الحقائق
غير المنشورة إلى الواجهة أو بيانات اللاعب قبل بوابة الكشف القصصية المناسبة.
يوثق `manifest.json` مصدر كل وثيقة وبصمة SHA-256 للمصدر الذي اعتمده المؤلف.
