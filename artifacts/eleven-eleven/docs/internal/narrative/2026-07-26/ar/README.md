# أرشيف السرد الداخلي

يحتوي هذا المجلد على مواد سردية مصدرية داخلية لمشروع **11.11**.

- **الرؤية:** داخلي فقط (`internal`)، وليس للنشر العام.
- **وقت التشغيل:** الملفات مرجعية ولا تدخل في حزمة اللعبة أو مسار وقت التشغيل (`runtimeIncluded: false`).
- **الحرق:** المحتوى يتضمن حرقًا كاملًا للقصة (`spoilerLevel: full`).
- **الحالة القانونية السردية:** مواد مصدرية بانتظار المطابقة والمصالحة مع النسخة القانونية النهائية (`source-material-pending-reconciliation`).

يجب مراجعة أي اقتباس أو تحويل من هذه المواد قبل اعتماده داخل اللعبة. يثبت `manifest.json` مصدر كل ملف وبصمة SHA-256 المدققة الخاصة به.
