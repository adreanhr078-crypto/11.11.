# سلطة قصة 11.11 الحالية

هذا المجلد هو المصدر السردي المعتمد للمشروع. حُذف أرشيف `Long Fall` السابق
بأمر المالك لأنه لم يعد يمثل القصة وقد يسبب تناقضًا.

## ترتيب السلطة

1. تعليمات المالك المباشرة.
2. `story-bible--echo-network.ar.md` للحقائق والقواعد والتسلسل العام.
3. `narrative-master--echo-network.ar.md` للإيقاع والمشاهد والتنفيذ الدرامي.
4. صفحات المانهوا المكتملة والمعتمدة بعد إضافتها إلى manifest بإصدار جديد.

المرجعان الأولان معتمدان معًا ومتطوران. عند ظهور تعارض لا يخترع المطور حلًا؛
يُسجل التعارض ويُعاد إلى المالك. بنية اللعب والمكافآت لا تستنتج مباشرة من
نص سردي غير محول إلى عقد Gameplay موثق.

## قرارات مقفلة

- Echo هو البطل والشخصية الرئيسية؛ Yuki صاحب الشعر الأبيض هو صديق طفولته.
- علامة Echo المباشرة على جلد الرقبة هي `EX-011`.
- طبقة Zero البصرية قابلة للإضافة والتطور، ولا تستبدل الرقم الأساسي.
- لا نص مقروء مدمج داخل صورة أو Blender/GLB/فيديو إنتاجي.
- Zero لا يظهر كاملًا قبل انهيار Echo النفسي وفق الـStory Bible.

راجع `manifest.json` لبصمات المصادر وحالة النشر.
