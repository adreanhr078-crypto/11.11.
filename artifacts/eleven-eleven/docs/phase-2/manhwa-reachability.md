# Phase 2 Manhwa Reachability

The Manhwa Archive contains 29 registered Chapter 01 pages.

- Page 01 is free.
- Pages 02–03 cost 3 Memory Shards each.
- Pages 04–05 cost 4 Memory Shards each.
- Pages 06–29 cost 5 Memory Shards each.
- Total paid cost for Pages 02–29: **134 Memory Shards**.

The current Chapter 01 campaign defines 20 unique shard rewards. With a new
save and no other shard source, sequential purchases can spend 19 shards to
unlock through Page 06, leaving 1 shard. Page 07 costs 5, so Pages 07–29 are
not reachable in the current economy.

This report does not change prices, mint shards, or modify puzzle rewards.
Future content may extend reachability by granting additional canonical shard
IDs through the existing progression transaction.
